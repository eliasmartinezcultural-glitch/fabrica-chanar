# Curaduría Fábrica Chañar

## Regla principal

La Fábrica no representa "Patagonia" de forma genérica. Representa **San Patricio del Chañar**.

Cada producto debe partir de un motivo territorial identificable y verificable.

## Jerarquía de fuentes

1. Municipalidad de San Patricio del Chañar.
2. Turismo Neuquén / NeuquenTur.
3. Neuquén Informa.
4. Sitios oficiales de establecimientos y organizaciones locales.
5. Medios regionales para contexto y archivo.
6. Redes sociales públicas de organismos, establecimientos y proyectos locales.

## Curaduría visual

Una imagen entra al Atlas solo si se puede asociar razonablemente con un lugar, actividad, evento, establecimiento o paisaje de San Patricio del Chañar.

No se debe confundir "fotografía bonita de Neuquén" con "fotografía de Chañar".

## Derechos

- `usable`: licencia o permiso compatible con el uso previsto.
- `reference`: imagen pública utilizada para investigación/visualización; no implica permiso comercial.
- `own`: material propio de Ocarina o aportado con permiso.

La Fábrica no debe presentar una imagen `reference` como libre de derechos.

## Dirección de arte

Las fotografías no son decoración. Determinan el tratamiento visual.

- Agua/río: amplitud, horizonte, aire, reflejos.
- Chacra/fruta: textura, proximidad, materia, trabajo.
- Vino/bodega: profundidad, arquitectura, contraste, elegancia.
- Fiesta: ritmo, movimiento, color y comunidad.
- Estepa/bardas: espacio, silencio, geometría y horizonte.
- Cultura: composición editorial, capas, memoria y detalle.

## Redacción

Los textos deben ser breves, específicos y verificables. Evitar frases turísticas genéricas como "un lugar mágico" cuando no aportan información.

La prioridad es que cada pieza pueda leerse como una pequeña obra editorial sobre Chañar.

## Objetivo de producto

**Mucha preestructura → mucha dirección de arte → mínima intervención → pieza terminada → descargar.**
