# Datos territoriales

Esta carpeta será la base documental de Fábrica Chañar.

## Regla principal

Un dato local no se considera confirmado por estar escrito en internet. Cada registro deberá indicar su estado:

- `verificado`
- `pendiente`
- `a_confirmar`
- `aporte_ocarina`
- `fuente_externa`

No se incorporan nombres, fechas, coordenadas, direcciones, teléfonos, horarios, estadísticas o hechos históricos sin una fuente identificable.

## Próxima etapa

Se incorporarán archivos JSON independientes para lugares, fuentes, historia, categorías y cartografía, evitando una base de datos cerrada o dependiente de un servicio pago.
